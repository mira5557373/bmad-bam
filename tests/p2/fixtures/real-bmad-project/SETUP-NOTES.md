# real-bmad-project fixture — setup notes

## Purpose

Minimal BMAD-initialized project shape for P2.1's real-install end-to-end test (`tests/p2/run-real-install-test.sh`).

## Origin

This fixture was hand-constructed to represent the post-`bmad init` state of a host project, NOT generated by running the actual `bmad init` command.

A fully real fixture would require:
- Working `bmad-method` CLI installed
- Running `bmad init` in this directory
- Accepting interactive prompts

The hand-constructed minimal shape is sufficient for P2.1's test purpose: it exercises the Path B finalize flow, which only requires:
1. A `_bmad/` directory the activation script can write to
2. A `_bmad/config.toml` marker (presence indicates a BMAD project)

## When to regenerate

If BMAD changes the shape of what `bmad init` produces (new required files, different config schema), regenerate by:

1. In a scratch dir: `bmad init` (with the BMAD version under test installed)
2. Diff the produced directory against this fixture
3. Update the fixture, document the BMAD version in this file

## Current BMAD version

This fixture targets BMAD **6.6.0** (the version submoduled at `external/bmad-method/` as of 2026-05-12).

If the test fails on a later BMAD, check whether the failure is due to config shape drift; if so, regenerate the fixture.
