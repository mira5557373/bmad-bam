# Step 01: Gather Decision Context

## MANDATORY EXECUTION RULES

- NEVER generate ADR without understanding decision context
- Load governance patterns before proceeding
- Pause after gathering context for user confirmation

---

## YOUR TASK

Gather architecture decision context including:
- Decision title and scope
- Stakeholders and deciders
- Decision drivers and constraints
- Problem statement

---

## Main Sequence

### 1. Load Governance Patterns

Read: `{project-root}/_bmad/bam/data/patterns/governance-*.md`

### 2. Gather Context

| Dimension | Question |
|-----------|----------|
| Decision Title | What is the architectural decision being made? |
| Problem Statement | What issue is motivating this decision? |
| Stakeholders | Who are the decision makers? |
| Drivers | What factors are driving this decision? |
| Constraints | What limitations must be considered? |
| Options | What alternatives are being considered? |

### 3. Confirm Context

Present summary and await user confirmation.
