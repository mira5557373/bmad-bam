# Step 05: Generate Decision Record

## YOUR TASK

Generate the architecture decision record (ADR) using the template.

---

## Main Sequence

### 1. Load Template

Load: `./templates/decision-log.md`

### 2. Fill Decision Record

Populate all sections based on gathered context:

| Section | Content |
|---------|---------|
| Status | Proposed, Accepted, Deprecated, or Superseded |
| Context | Problem statement and background |
| Decision Drivers | Factors influencing the decision |
| Considered Options | Alternatives evaluated |
| Decision | Selected option with rationale |
| Consequences | Positive, negative, and neutral impacts |
| Validation | Success criteria for the decision |

### 3. Write Document

Write to: `{output_folder}/planning-artifacts/decision-log.md`

### 4. Verify

Confirm document completeness with user.

---

## SUCCESS METRICS

- All template sections populated
- Context clearly explained
- Alternatives documented
- Consequences identified
- **CRITICAL:** Decision documented with tenant impact
